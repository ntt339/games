## 🚀 Adding Future Games
To add a new game in the future:
1. Create a new subfolder: e.g. `chess/` or `pool/`
2. Add `index.html`, `privacy-policy.html`, `support.html`, and `terms.html`
3. Add a game card entry in the root `index.html` portal
4. Commit and push to `main` branch
